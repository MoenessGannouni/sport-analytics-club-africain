# sport-analytics-club-africain

## 📌 Description du Projet
Ce projet vise à analyser et structurer les données sportives et médicales des joueurs du **Club Africain**.  
Nous avons généré des données réalistes et les avons organisées dans des tables exploitables pour l’analyse.

## 📊 Objectifs
- Préparer une infrastructure de données sportives pour faciliter la transformation numérique axée sur
  les données pour le **Club Africain**.
- Concevoir des tableaux de bord interactifs et des outils de reporting pour la visualisation en temps réel
  des performances sportives.
- Développer des outils d'analyse avancée avec IA pour évaluer, prédire et optimiser les performances
  des joueurs.
- Mettre en place un système de génération de rapports automatisés sur les performances.

## 📂 Structure du Repo
- `data/` : Contient les fichiers CSV des données générées.
- `notebooks/` : Contient le notebook Jupyter pour la génération des données.
- `docs/` : Contient le dictionnaire des données (`Dictionnaire_Donnees.docx`).
- `requirements.txt` : Liste des dépendances Python.
- `README.md` : Ce fichier !

## 🛠️ Technologies utilisées
- **Python** (pandas, faker, timedelta, random)
- **Jupyter Notebook**
- **GitHub** pour la gestion du projet
